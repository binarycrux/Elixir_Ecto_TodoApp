# Elixir Todo App with Ecto:
This is a simple Elixir Todo app project built with Ecto. The app uses PostgreSQL as the database.

## Configuration:
Before running the app, ensure that you update the /config/config.exs file with your PostgreSQL login credentials.

## Requirements:
Elixir/Erlang installed,
PostgreSQL installed

### How to Run the App:
Clone the repository and navigate to the /todo_ecto/ directory.

Once in the directory, start an interactive Elixir shell by running:
```elixir
iex -S mix
```
After the shell is launched, type the following command to start the app:
```elixir
TodoEcto.start
```
